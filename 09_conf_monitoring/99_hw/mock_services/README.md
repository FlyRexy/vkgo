# Mock External Services

Имитация трёх внешних сервисов для домашнего задания №9.

## Что это делает

Запускает 3 "кривых" сервиса, которые по SLA должны работать хорошо, но на деле — нет.

### Thread Service (`:15000`)
- **SLA:** ~10ms, 100% 200
- **Реальность:**
  - 3% запросов возвращают 500
  - 15% запросов имеют latency 30-200ms (нарушение 2x SLA)
  - 5% запросов имеют latency 300-800ms (жёсткое нарушение SLA)

### Comment Service (`:16000`)
- **SLA:** ~20ms, 100% 200
- **Реальность:**
  - 5-6% запросов возвращают 500
  - 20% запросов имеют latency 100-500ms
  - 10% запросов имеют latency 500-1500ms (жёсткое нарушение SLA)

### Auth Service (`:17000`)
- **SLA:** ~5ms, 0% 500
- **Реальность:**
  - **5% запросов возвращают 500** (SLA обещает 0%!)
  - 8% запросов имеют latency 50-200ms (нарушение 2x SLA = 10ms)

### Вечерний даунтайм (19:00-21:00)
Все сервисы начинают возвращать 503 с latency 1-3 секунды.
Для опционального задания (3 доп. балла) про алерты.

## Запуск

### Вариант 1: Нативно (Go)

```bash
go run main.go
```

### Вариант 2: Docker Compose

```bash
docker-compose up --build
```

### Вариант 3: Сборка бинарника

```bash
go build -o mock_services main.go
./mock_services
```

## Настройка основного сервиса

В репозиториях основного сервиса нужно заменить адреса внешних сервисов:

| Оригинал | Заменить на |
|---|---|
| `http://vk-golang.ru:15000` | `http://localhost:15000` |
| `http://vk-golang.ru:16000` | `http://localhost:16000` |
| `http://vk-golang.ru:17000` | `http://localhost:17000` |

Или можно добавить в `/etc/hosts`:
```
127.0.0.1 vk-golang.ru
```
